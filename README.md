# Muslim
*"Muslim" is a phone app made for Muslims. It helps you with your faith and makes practicing Islamic habits easier.*

*This app was developed using the Flutter Framework and employs the "Bloc" package for effective management of the application's state.*

*Furthermore, "Muslim" is available in both English and Arabic languages and also offers a Dark mode option for a comfortable user experience.*

## GETTING INTO THE PROJECT:
Muslim application supports English and Arabic languages and Light and Dark modes.

**It contains 5 main pages:**

&nbsp; &nbsp; &nbsp; 1. Quran.

&nbsp; &nbsp; &nbsp; 2. Hadeth.

&nbsp; &nbsp; &nbsp; 3. Azkar.

&nbsp; &nbsp; &nbsp; 4. Tasbeh.

&nbsp; &nbsp; &nbsp; 5. Settings.

&nbsp;

**Quran page:**

&nbsp; &nbsp; &nbsp; Here you can open and read all Quran Suras by clicking on the desired one.
